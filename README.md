# Not Defteri Uygulaması

Bu basit C programı, kullanıcının metin ekleyebilmesini, düzenleyebilmesini, silebilmesini ve notları listeleyebilmesini sağlayan bir not defteri uygulamasıdır.

## Özellikler

- Not ekleme
- Not düzenleme
- Not silme
- Notları listeleyebilme

## Kullanım

Programı çalıştırdığınızda, bir menü karşınıza çıkacaktır. Menüdeki seçeneklere göre not ekleyebilir, düzenleyebilir, silebilir ve listeyebilirsiniz.
